# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/FloydSchool.git
```

Go inside

```bash
cd FloydSchool
```

Install dependencies

```bash
npm install
```

Start Frontend

```bash
npm run dev
```

Start Backend

```bash
npm run server
```

# 🌍 Environment Variables

Create a `.env`

```env
PORT=

MONGO_URI=

JWT_SECRET=

GOOGLE_CLIENT_ID=

GOOGLE_CLIENT_SECRET=

RAZORPAY_KEY_ID=

RAZORPAY_KEY_SECRET=

CLIENT_URL=
```
